# Linux Systems Support Lab

This project simulates the daily responsibilities of a Service Engineer supporting Linux-based systems in production environments.

The lab focuses on:

- Linux administration
- User management
- SSH support
- Network troubleshooting
- DNS troubleshooting
- Service monitoring
- Incident response
- Technical documentation

The goal was to develop and demonstrate practical troubleshooting and support skills commonly required in technical support and field service engineering roles.

## Environment

Host:

- Windows 11

Virtualization:

- Oracle VirtualBox (via Vagrant)

Guest OS:

- Ubuntu Server 20.04 LTS

Services:

- OpenSSH
- Apache2
- FTP
- Systemd

Tools:

- ping
- traceroute
- nslookup
- ssh
- scp
- journalctl
- netstat
- ss

## Skills Demonstrated

- Linux Administration
- User & Group Management
- SSH Configuration
- Network Diagnostics
- DNS Troubleshooting
- Firewall Configuration
- Service Monitoring
- Log Analysis
- Root Cause Analysis
- Technical Documentation
